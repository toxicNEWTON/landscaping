PANLABAS LANDSCAPING — FUTURISTIC WEBSITE CONCEPT
=================================================

HOW TO PREVIEW
1. Extract the entire ZIP into one folder.
2. Open index.html in Chrome, Edge, Firefox, or Safari.
3. Scroll down and test the sections. Use the moon icon in the top-right to switch between the original colorful logo and pure white logo.
4. No Node.js/npm or installation is required. All image, stylesheet, logo, and script assets are included in local folders.

HOW TO UPLOAD
- Upload the *contents* of the extracted folder (index.html + assets directory) to your hosting website root/public_html, preserving the folder structure.
- Verify that index.html and assets/ sit alongside each other after upload.
- Because paths are relative, no external image host or third-party CSS/JavaScript CDN is required.

- Cinematic responsive hero and editorial typography.
- Colorful / dark theme switch (saved in the visitor's browser when storage is available).
- Original colorful logo in light mode; fully white logo in dark mode.
- Mouse-follow glow and cursor ring (desktop pointer devices), magnetic hover CTAs.
- Scroll-reveal effects, image parallax, service rows and project hover treatment.
- 4 clickable project-concept image previews (click to enlarge; Escape closes).
- Light comparison slider showing DAYLIGHT vs EVENING adjustments on the SAME illustrative scene. It is not an actual real-world before/after.

- Instagram link: https://www.instagram.com/emmacalzado98
- X/Twitter and TikTok footer icons are intentionally NOT linked pending URLs.

IMPORTANT BEFORE GOING LIVE
- All scenic photos were AI-generated as mood/visual concept assets and DO NOT represent verified PANLABAS completed projects. Replace them with real authorized project photos before claiming past work. The website explicitly calls the gallery illustrative.
- Service offerings are proposal/placeholder descriptions, not independently verified offerings. Confirm them with the business before publishing.
- The enquiry form is a FRONT-END DEMO only: it prepares text to copy and send via Instagram. It does not email a company inbox or transmit to a server. Connect to a secure backend/form service if you need real form submissions.
- Replace/add real company phone, email, WhatsApp, TikTok and X URLs once provided. None were invented.
- For production, consider adding legal/privacy pages and privacy-safe analytics if desired.

CUSTOMIZATION
- Replace the files in assets/images/ with new images using the same file names, or change the paths in index.html.
- Change heading/sections/services in index.html.
- Edit background and accent variables under :root and html[data-theme="dark"] at the start of assets/css/styles.css.
- Edit social URLs in index.html. Keep the Instagram URL if it is approved.
